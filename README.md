# Kudzu Nuzlocke Tracker (web)

The playtester build of the Kudzu tracker, served by GitHub Pages.

Everything here is generated by `tools/build_web.py` in the kudzu-tracker repo
and is overwritten on every build - edit the tracker, not these files. To update:
press Refresh data in the desktop tracker, then run

    python tools/build_web.py --publish

Your run and save stay in your own browser; nothing is uploaded. Use All runs >
Export to keep a copy of a run or send it on.
